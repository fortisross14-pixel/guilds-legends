# Hand-painted art (generated)

Made by `scripts/art/import_myart.py` from the private art repository
(Unity Asset Store packs: 2D Hand Painted Tilesets, GUI PRO Kit - Fantasy RPG,
HeroEditor). Only the pieces the game uses are here. Licensed under the Unity
Asset Store EULA: for use inside this game only, not for redistribution, which is
why the game repository is private. Credits in `CREDITS.md`.

Do not edit these files by hand; change the script (or `scripts/art/characters.py`
for the walking characters) and run it again.
